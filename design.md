# AliBuyra Marketplace - Design System

## Design Philosophy

### Color Palette
- **Primary**: `#00BFA6` (Teal - Fintech Trust)
- **Secondary**: `#1B263B` (Deep Navy - Premium AI Look)
- **Accent**: `#FFD700` (Gold - Success & Profit)
- **Background Light**: `#F7F9FA`
- **Background Dark**: `#0D1117`
- **Gradient**: `linear-gradient(45deg, #00BFA6, #6A00F4)`

### Typography
- **Display Font**: Canela (Bold serif for headings)
- **Body Font**: Neue Haas Grotesk (Clean sans-serif for content)
- **Accent Font**: Space Grotesk (Modern sans-serif for UI elements)

### Visual Language
- **Aesthetic**: Modern fintech meets premium marketplace
- **Mood**: Trustworthy, innovative, profitable
- **Style**: Clean minimalism with strategic color accents
- **Inspiration**: Apple-like simplicity with AI-driven intelligence

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth micro-interactions and element animations
- **ECharts.js**: Real-time income dashboard visualizations
- **Splide.js**: Product carousels and image galleries
- **p5.js**: AI recommendation visual effects
- **Pixi.js**: Advanced visual effects for hero sections

### Animation Effects
- **Text Effects**: 
  - Color cycling emphasis on key metrics
  - Split-by-letter stagger for hero headings
  - Gradient text animation for CTAs
- **Image Effects**:
  - Infinite image scroller for product showcases
  - Ken Burns pan/zoom on hero images
  - Hover-activated 3D tilt effects

### Header & Background Effects
- **Aurora Gradient Flow**: Dynamic background with teal-to-purple gradient
- **Floating Particles**: Subtle p5.js particle system for AI visualization
- **Liquid Metal Displacement**: Premium background effect for dashboard

### Interactive Elements
- **Product Cards**: 
  - Hover lift with shadow expansion
  - Color morphing borders
  - Real-time price update animations
- **Buttons**:
  - Glow edges on hover
  - Gradient background shifts
  - Smooth scale transitions
- **Charts & Data**:
  - Animated chart transitions
  - Real-time data updates
  - Interactive hover states

### Responsive Design
- **Mobile-First**: Optimized for touch interactions
- **Tablet**: Adaptive grid layouts
- **Desktop**: Full-featured experience with hover effects

### Accessibility
- **Color Contrast**: 4.5:1 minimum ratio maintained
- **Focus States**: Clear keyboard navigation
- **Screen Reader**: Semantic HTML structure
- **Motion**: Respects prefers-reduced-motion

## Component Styling

### Navigation
- **Style**: Glass morphism with teal accents
- **Animation**: Smooth slide-in transitions
- **Active State**: Gold accent with subtle glow

### Product Cards
- **Layout**: Grid with consistent spacing
- **Hover**: 3D tilt with shadow depth
- **Image**: Aspect-ratio maintained with object-fit
- **Typography**: Hierarchical with clear pricing

### Dashboard Elements
- **Charts**: Clean, minimal with brand colors
- **Metrics**: Large, bold numbers with animations
- **Cards**: Subtle shadows with hover elevation
- **Progress**: Smooth animated progress bars

### Form Elements
- **Input Fields**: Clean borders with focus states
- **Buttons**: Gradient backgrounds with hover effects
- **Validation**: Real-time feedback with color coding
- **Accessibility**: Clear labels and error messages
